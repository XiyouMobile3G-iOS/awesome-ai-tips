# Awesome AI Tips

本仓库用于整理 AI 相关知识，沉淀提示词、工作流、工具用法与实践笔记。

面向 [XiyouMobile3G · iOS](https://github.com/XiyouMobile3G-iOS) 实验室同学，持续补充可复用的 AI 使用经验。

## 这是什么

这里不是代码项目，而是一份持续更新的 AI 知识库，用来记录：

- 常用 AI 工具与使用方式
- 可复用的提示词和工作流
- 开发、学习过程中值得保留的实践

目标是把散落的经验集中起来，方便查阅和共建。

## 如何使用

直接阅读仓库中的文档即可。后续会按主题补充条目，例如提示词、Agent 工作流、工程实践等。

## 如何贡献

欢迎通过 [Issue](https://github.com/XiyouMobile3G-iOS/awesome-ai-tips/issues) 或 [Pull Request](https://github.com/XiyouMobile3G-iOS/awesome-ai-tips/pulls) 补充资料、修正内容。
